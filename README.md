# DUO Charity — сайт с админкой, каруселью и 3 языками

## ⚠️ ВАЖНО: как поставить этот архив поверх старого проекта (по шагам)

Чтобы ничего не сломалось и не перепуталось со старыми файлами, сделай **именно так**:

1. Останови сервер в терминале VS Code: `Ctrl + C`
2. Закрой VS Code полностью (это важно — иначе Windows может не дать удалить открытые файлы)
3. Открой обычный Проводник Windows, зайди в `Desktop`
4. **Удали папку `DuoCharity` целиком** (правой кнопкой → Удалить). Не бойся —
   мы её сейчас пересоздадим с нуля из архива, никакой код не потеряется,
   единственное что может потеряться — загруженные тобой тестовые фото
   (это не страшно, можно перезагрузить заново)
5. Распакуй скачанный `duocharity.zip` **прямо на Рабочий стол** (правой кнопкой
   на zip → "Извлечь всё..." → выбери "Рабочий стол" как место)
6. После распаковки у тебя на столе появится папка `duocharity` —
   **переименуй её** в `DuoCharity` (чтобы совпадало с тем, что было)
7. Открой эту папку в VS Code (File → Open Folder)
8. Открой терминал в VS Code, и выполни по очереди:

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

(`venv` мы создаём заново — это быстро, 1-2 минуты, зато не будет путаницы
со старым окружением)

9. Открой браузер: **http://127.0.0.1:5000**

## Вход в админку

1. Открой **http://127.0.0.1:5000/admin/login**
2. Логин: `admin`
3. Пароль: `changeme123`
4. Сразу смени пароль в разделе "Sozlamalar" (там форма смены пароля внизу)

## Что нового в этой версии

### 🌍 Мультиязычность (узбекский / русский / английский)
- Переключатель с флагами в шапке сайта (справа, рядом с кнопкой "Yordam berish")
- На телефоне — внутри открывающегося мобильного меню
- Выбор языка запоминается (через cookie), при следующем визите сохраняется
- Все тексты на сайте переведены: меню, главный экран, статистика, о нас,
  галерея, новости, донаты, форма волонтёра, футер

### 🖼️ Карусель фото на главном экране (Hero)
- В админке новый раздел **"Hero karusel"** (в боковом меню)
- Загружаешь туда несколько фото — на главной странице они будут
  автоматически переключаться каждые 5 секунд
- Можно листать вручную: стрелки по бокам, точки снизу
- Если фото нет — показывается обычная серая заглушка, как раньше

## Структура проекта

```
duocharity/
├── app.py                    ← основная логика (роуты, публичный сайт + админка)
├── models.py                 ← структура базы данных
├── translations.py           ← словарь переводов на 3 языка
├── init_db.py                ← скрипт первого запуска
├── duocharity.db              ← база данных (создаётся автоматически)
├── requirements.txt
├── templates/
│   ├── base.html               ← каркас публичного сайта (с переключателем языка)
│   ├── index.html              ← главная страница (с каруселью)
│   └── admin/                  ← страницы админки
│       └── hero.html             ← управление каруселью (новый файл)
└── static/
    ├── css/style.css           ← стили сайта (с каруселью, переключателем языка)
    ├── css/admin.css
    ├── js/main.js               ← логика карусели, языка, мобильного меню
    ├── images/
    └── uploads/                 ← сюда попадают все загруженные через админку фото
```

## Важно про базу данных

Файл `duocharity.db` — вся твоя база данных. Не удаляй его без причины,
там хранятся новости, фото, заявки волонтёров, настройки. Если хочешь
сделать резервную копию — просто скопируй этот файл куда-то в безопасное место.

## Как это работает "под капотом" (для понимания)

- **Карусель** — фото берутся из таблицы `HeroImage` в базе данных,
  загружаешь их через `/admin/hero`, JavaScript на странице (`main.js`)
  сам переключает слайды каждые 5 секунд и обрабатывает клики на стрелки/точки
- **Язык** — при заходе на сайт Flask смотрит cookie `lang` в браузере
  (`uz` по умолчанию, если cookie нет). Все тексты берутся из `translations.py`
  через функцию `t('ключ')` в шаблонах. При клике на флаг — переходишь на
  `/set-language/ru` (или `/en`, `/uz`), это устанавливает cookie на год
  и возвращает тебя туда же, где ты был
